# LanHua Club - Planificador de Clases (To-Do Project)

Este proyecto forma parte del Sprint 1 individual de Generation Colombia Se trata de una aplicación To Do diseñada específicamente para los entrenadores del **Club Deportivo LanHua**, permitiéndoles organizar su agenda de clases de forma rápida.

## Tecnologías y Herramientas Utilizadas

Durante el desarrollo de este sprint trabajamos con las bases del desarrollo web y control de versiones:
* **HTML5** (Estructura semántica)
* **CSS** (Estilos personalizados basados en el Manual de Marca Lan Hua)
* **Bootstrap 5** (Componentes responsivos)
* **JavaScript (Vanilla)** (Lógica del formulario y Manipulación del DOM)
* **Git y GitHub** (Control de versiones)
* **IntelliJ / Spring Boot Structure** (Estructura de archivos orientada a backend en Java)

---

## Funcionalidades Principales

1. **Formulario de Registro de Sesiones:** Permite seleccionar la disciplina (Wushu, Sanda, Taolu, Tai Chi), el nivel (Principiante, Intermedio, Avanzado), la sede de entrenamiento, fecha, hora y observaciones.
2. **Validación en JavaScript (`validFormFieldInput`):** Verifica que todos los campos requeridos estén completos antes de permitir la creación de la clase, mostrando una alerta  en caso  de que falte información.
3. **Generación Dinámica de Tarjetas:** Crea una tarjeta organizada por cada clase agendada con un contador en tiempo real de la cantidad de clases programadas.
4. **Interacción de Tareas:** Incluye casillas para marcar clases como completadas y botones funcionales para cancelar.
